## Run the application

Each stage is a separate complete service. Follow its unchanged `RUN.md`. For the final application:

```sh
cd stage-4
docker build -t tablekeeper-stage-4 .
docker run --rm -e PORT=8080 -p 8080:8080 tablekeeper-stage-4
```

Open `http://localhost:8080/`; readiness is `GET /health`. State is in memory, with contract-defined atomic export/import. The running application needs no model, external API key or paid service.
